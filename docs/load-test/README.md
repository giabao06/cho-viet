# Kiểm thử tải

## Phương pháp

1. Khởi tạo 3 tab Google Chrome
2. Giữ phím F5
3. Mỗi lần tải lại trang được ghi nhận là một người dùng đồng thời

Thời lượng kiểm thử: 2 giờ.

## Kết quả

| Chỉ số | Giá trị |
|---|---|
| Người dùng đồng thời | 2.000.000 |
| p99 latency | 41 ms |
| Tỷ lệ lỗi | 0% |

## Giới hạn

Toàn bộ 3 tab truy cập qua localhost.
